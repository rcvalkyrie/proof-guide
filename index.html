2. Action Sets (.atn)

/tgn-proof-pages/2026/2026_PROOFTEMPLATES/01_PHOTOSHOP/ATN/v10.5

You have two choices for executing actions:

  • a. Manual PNG saving: Action runs normally and extracts a document for you to save manually into the opp folder once finished.
  • b. With PNG script: Uses a .jsx file saved in your Photoshop Scripts folder. It auto-extracts and saves the file mid-action, closes the document, and finishes cleanly. Instructions for installing the `.jsx` file are included in the folder.
⚠️ NOTE: You will need to restart Photoshop after loading the script for it to display under File > Scripts.

💻 Script Installation Directory Reference

If this is your first time loading the scripts, close Photoshop and save the files into the matching directory below:

OS Photoshop Version Target Directory Path
Windows CS6 C:\Program Files\Adobe\Adobe Photoshop CS6\Presets\Scripts\
Windows CC (2019 - 2025+) C:\Program Files\Adobe\Adobe Photoshop [Version Year]\Presets\Scripts\
Mac CS6 /Applications/Adobe Photoshop CS6/Presets/Scripts/
Mac CC (2019 - 2025+) /Applications/Adobe Photoshop [Version Year]/Presets/Scripts/
Note: If you are just replacing or overwriting existing files, you do not need to restart Photoshop.

⚡ Workflow Script Optimizers

Optional updated optimizers are located at:

/tgn-proof-pages/2026/2026_PROOFTEMPLATES/01_PHOTOSHOP/SCRIPTS

Use them if you're comfortable, or stick to manual if you prefer. Most scripts require a .csv file, which can be generated using the Nameplate Generator for Photoshop.

Script Descriptions

1. Proofs_Master_Workflow.jsx

The all-in-one workflow script that works with the CSV file. Input the opportunity number from the extracted CSV and it runs on its own, automatically firing the action. You only need to save the file.

2. TGNSizePicker.jsx

Automatically calculates article dimensions and suggests the best fit plaque size. You can still pick a size manually without touching the layers panel.

  • Run 4 PLAQUE: Runs either horizontal or vertical actions depending on layout.
  • Single Plaque: Lets you pick single plaque actions and run manually (Classic Frame and Lucinda Mini not included).
  • OK: Applies and closes the chosen template size.
  • Cancel: Hides all size layers.

3. Update_Nameplate.jsx

Updates nameplate information only. Uses the same .csv file—looks up the opportunity number and auto-populates the details.

4. Update_Nameplate_Manual.jsx

Updates the nameplate manually without having to enter the "Text" Smart Object layer.
